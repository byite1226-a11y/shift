# Gate 01 구현 보고 — 2026-10-15

구현 완료 ≠ 플레이테스트 완료. 아래 "검증됨"은 자동 테스트와 Playwright 스크립트로 확인한 항목이고, 재미·조작감·실제 인간 플레이 평가는 `docs/brief/05_playtest_gate.md` 절차로 별도 진행해야 한다.

## 1. 실행 / 테스트

```bash
npm install
npm run dev      # http://localhost:5173  (?mode=A|B|C&seed=42 로 모드·seed 지정 가능)
npm test         # vitest: 3 files, 26 tests — 전부 통과
npm run build    # tsc --noEmit + vite build — 통과 (dist/ 21 KB JS, 4.7 KB CSS)
```

## 2. 스택 선택 이유

빈 저장소였고 C:\dev 에도 재활용할 게임 엔진이 없었다. 지시서의 "TypeScript + Vite + PixiJS 혹은 최소 구성" 중 **Vite + TypeScript + Vitest, 렌더링은 Canvas 2D**를 택했다.
시안이 단순 벡터 도형(마름모·링·짧은 다트)이라 PixiJS(WebGL 씬그래프)는 이득 없이 번들과 학습 비용만 늘린다. 런타임 의존성은 0개, 개발 의존성은 vite / typescript / vitest 셋뿐이다.

## 4. 자동 테스트 결과 (vitest, 26/26 통과)

- 기하: 스윕 판정이 한 스텝에 플레이어를 관통하는 투사체를 잡음(tunneling 방지), client→논리 좌표 변환(0.5×, 1.5×, 화면 밖)
- 스케줄: 같은 seed 재현 / 다른 seed 상이, 페이즈별 간격·속도·발수 준수, 패턴 내 변 중복 없음, 스폰 위치는 항상 필드 가장자리 바깥 14 px
- 시간: 60 Hz와 144 Hz 프레임으로 돌려도 게임 시간·플레이어 위치·스폰 수 동일. 5000 ms 프레임 하나는 최대 50 ms만 진행. 일시정지 중 시간·스폰·입력 정지
- A/B: 최고속도·피격반경 동일(설정 검증), 같은 seed → 동일 스폰 시점·위치(입력과 무관), 대각선 정규화, 필드 클램프, 포인터 순간이동 시 플레이어는 최대속도로만 접근, 3 px 이내 정지, 필드 밖 포인터 클램프, 동시 2발 피격도 game_over 1회, near-miss 1회 발생(중심거리 20 px)
- C: 15 px 이내 클릭 제거, 16 px는 miss, 빈 공간 클릭은 miss 기록만, 350 ms 미만 잔여 시 close save, 코어 도달 시 core_breach 1회
- 40초 생존 → CLEAR, survivalMs = 40000, 샘플 ≤ 401개

## 6. 기획·시안과 다른 부분

1. **시안의 점선 접근 궤적선은 그리지 않았다.** 궤적을 보여주면 회피/요격 난이도와 판단 방식이 달라져 비교 실험을 오염시킨다. 꼬리로만 방향을 표시한다. 원하면 render.ts에 한 줄로 켤 수 있다.
2. **패턴 "엇갈림/서로 다른 방향"**은 "한 패턴의 투사체는 서로 다른 변에서 출발"로만 구현했다. "실현 가능한 탈출 경로 보장"은 변 중복 금지 + 패턴당 최대 3발 + 고정 직선 조준으로 구조적으로만 확보했고, 별도 탐색 테스트는 없다.
3. **코어 피격 기준**: 투사체 중심 ↔ 코어 중심 거리 ≤ 18 + 7 = 25 px(판정 반경 합). 플레이어 피격도 8 + 7 = 15 px. 시각 반경(22, 10)보다 판정이 작거나 같다.
4. **카운트다운**은 숫자 대신 플레이어/코어 둘레의 1초 링 아크.
5. **B의 시작 시점**: 카운트다운 중에는 중앙 고정, PLAYING 진입과 동시에 포인터 위치로 추적을 시작한다. 포인터가 멀리 있으면 첫 프레임부터 그쪽으로 달려간다(스펙 "시작 지점은 필드 중앙" 준수, 다만 체감 확인 필요).
6. **결과창에 seed 한 줄**을 작게 표시한다. 스펙은 생존시간·최고기록만 허용하지만 플레이테스트 재현에 필요해 넣었다. 진단·백분위·반응속도는 없다.
7. **세부 로그는 localStorage에 저장하지 않는다.** 메모리에 최근 10판만 보관하고 디버그 패널에서 JSON으로 내려받는다. 판 결과(모드·seed·생존시간)는 localStorage에 최근 200판까지 저장.
8. 십자 표식은 시안의 링에 4개 틱을 더한 형태(B 세이지, C 잉크). 투사체(코럴 다트)·플레이어(검은 마름모)와 구별된다.
9. 사운드 기본값 켜짐(제스처 전에는 어떤 소리도 나지 않음), 상단 버튼으로 끔. 키보드 단축키는 없음.

## 7. 알려진 제한 / 미검증

- 120/144 Hz 모니터 실측은 하지 않았다(고정 스텝 로직의 단위 테스트로만 확인).
- 지속적으로 20 fps 미만이면 세계가 건너뛰지 않고 느려진다(프레임당 50 ms 상한). 의도된 선택.
- 효과음, near-miss 링/"CLOSE!", close-save "SAVE!"의 **보이는 모습과 소리**는 눈·귀로 확인하지 못했다(이벤트 발생과 로그만 확인).
- `prefers-reduced-motion`은 VFX를 정지 프레임으로 바꾸는 분기만 있고 실제로 켜서 보지는 않았다.
- 브라우저 패널(Claude 내장)은 숨김 상태에서 requestAnimationFrame이 멈춰 플레이가 안 된다. 일반 브라우저에서 열어야 한다.
- 터치/모바일 미지원(데스크톱 우선 스펙).
- 라운드 중 R은 아무 동작 없음(스펙은 종료 후 재시작만 명시).
