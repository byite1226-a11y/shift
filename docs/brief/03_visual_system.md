# 03. SHIFT. Gate 01 비주얼 시스템

## 아트 디렉션

- 인디 아케이드 편집디자인: 날카로운 구조, 여백, 종이톤, 어두운 선, 소수의 신호색.
- 배경은 반응에 방해되는 구조물을 배제한다. 첫 시안의 건물·정교한 환경 요소는 **플레이 필드 안에 넣지 않는다**.
- 3개 모드는 같은 UI·색상·카메라·HUD·화면 비율을 공유하여 조작/메커니즘 비교를 방해하지 않는다.
- 점수 대신 생존시간을 맨 위에 크게 표시한다. 보조 정보는 현재 모드와 개인 최고기록 한 가지.

- 향후 다른 색상 테마가 추가돼도 기능별 명암 대비를 유지한다.

## 레이아웃

- 기본 목표 디스플레이: 데스크톱 1440 × 900 근처.
- 게임 논리 필드: 960 × 540; 주변에 최소 24px 패딩을 둔다.
- 화면 상단: 로고/모드(작음) | 타이머(큼) | 최고기록(중간).
- 화면 아래: 안내는 READY/첫 진입시에만 표시. PLAYING 중 주요 지시문 없음.
- 메뉴에서 A/B/C를 비교할 때 '키보드 회피 / 마우스 회피 / 마우스 요격'이라는 명확한 한국어 라벨 사용.

## 물체 디자인

- 플레이어: 매우 작은 차콜 마름모/원. 눈이나 캐릭터 표정 등은 첫 프로토타입에서 생략.
- 투사체: 가느다란 '접근 방향'을 나타내는 짧은 꼬리와 코럴색 팁. 죽림고수 화살 에셋을 복제하지 않는다.
- 코어: 단순한 차콜 링 + 점; 적과 확실하게 구분.
- 마우스 목표점: 얇은 검정 십자 또는 고리. 투사체와 혼동하면 안 된다.
- 판정 크기는 시각 크기와 관계를 명확하게 유지. 보이는 물체보다 보이지 않는 충돌영역이 크게 튀어나오면 안 된다.

## 모션

- 생성 80~120ms: 아주 짧은 등장 신호. 발사체가 화면 외곽에서 나오는 규칙을 흐리지 않는다.
- 처치 100~160ms: 작은 선 분리/압축 애니메이션. 화면 전체 흔들림 금지.
- near-miss 80ms: 플레이어 외곽 한 번의 얇은 링 확대.
- 충돌 종료: 최대 200ms 짧은 인지 가능한 피격 피드백 후 결과.
- 기본 모션은 `prefers-reduced-motion`에서도 판정 및 정보 전달을 잃지 않도록 구현.

## 사운드

- 외부 음악 파일 필수 아님. 간단한 생성형 짧은 효과음으로 출발.
- 생존 near miss, 요격 성공, 실패를 각각 짧게 구분.
- 첫 진입 자동재생 금지, 음소거 토글 제공.
- 반복 플레이 중 귀를 피로하게 하는 고주파·과도한 볼륨 금지.

## 시안 범위

`assets/preview_*.svg`는 브랜드/형태/레이아웃의 지시 자료이며 최종 컨텐츠 에셋이 아니다. 실제 플레이 테스트를 거친 뒤 모션과 표적 가독성을 기준으로 변경한다.
