# SHIFT. — Gate 03 Concept Art Package

## 목적
Gate 03 작업 시 참고할 확정 비주얼 레퍼런스와 화면 시안을 묶었습니다.

## 적용 우선순위
1. `01_Approved_Reference/Option_B_Original.png`: 사용자가 선택한 투사체 컨셉아트. **원본 외형과 스타일의 최상위 기준.**
2. `02_Screen_Concepts/01_Home.png`, `02_Gameplay_A.png`: 홈·플레이 화면의 시각적 방향 시안.
3. `02_Screen_Concepts/03_Game_Over_Clean.png`: 사용자가 긍정적으로 평가한 **최신 간결형 결과 화면**. 다른 결과 화면 디자인보다 우선.
4. `03_Projectile_Design/`: 투사체 시트·플레이 적용 참고 이미지 및 투명 PNG 소재.
5. `04_Additional_Style_References/`: HUD 세부 참고.

## 디자인 원칙
- 크림색 배경, 차콜색 외곽선, 코럴 일반탄, 세이지 대형탄.
- 투사체 실루엣, 전면 방향, 중앙 절개선 및 짧은 이동 잔상을 유지.
- 투사체 움직임 방향에 맞춰 회전하되 형태를 임의로 변경하지 않음.
- 발광·글로우·과도한 파티클·3D 효과를 추가하지 않음.
- 결과 화면에는 생존시간을 가장 크게; 전체 순위·상위 퍼센트는 실제 서버 데이터가 없으면 표시하지 않음(시안 속 숫자는 예시).

## 주의
- 이미지들은 **디자인 레퍼런스/합성 시안**이며 그대로 실행 가능한 UI 코드가 아닙니다.
- `Transparent_Assets` PNG는 기존 컨셉아트에서 추출한 래스터 소재입니다. 확대/축소에 따른 가독성, 배경 잔여물, 히트박스는 CC 구현 단계에서 검증해야 합니다.
- Game Over 시안의 최고 기록과 상위 퍼센트는 가상 예시 숫자입니다.
- 기존 Gate 02.2 코드와 Gate 03 기능 명세는 이 ZIP에 포함되지 않습니다.
