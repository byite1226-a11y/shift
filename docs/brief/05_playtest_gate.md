# 05. Gate 01 플레이테스트 계획

## 목적

'조작 장치'보다 '한 판의 핵심 재미'가 우선이라는 가설을 확인한다. 세 모드 A/B/C 중 하나를 최종 게임 방향으로 결정하거나 재설계를 선택한다.

## 참가자

- 1차: PC 경쟁 게임 경험이 있는 사용자 8~12명 정도의 빠른 질적 테스트.
- 특정 게임 장르에 편중되지 않도록 LoL/MOBA, Valorant/FPS, Overwatch/히어로 슈터 이용자를 균형 있게 모집.
- 결과를 통계적 일반화로 주장하지 않는다. 초기 사용성·재미 판단에 이용한다.

## 진행 순서

1. 5초 이하로 시작 설명: '최대한 오래 버텨보세요. 한 번 실패하면 끝납니다.'
2. A, B, C 각각 최대 3회 플레이.
3. 체험 순서는 참가자마다 A→B→C, B→C→A, C→A→B로 순환해 순서 효과를 줄임.
4. 조작 숙련도를 낮추기 위해 첫 판은 이해도를 확인하는 용도로 분류하고, 2~3판에서 기록 및 재미를 비교.
5. 세 모드 종료 후 강제 선택 + 간단한 심층 질문.

## 설문 5문항

1. 어떤 모드를 다시 해보고 싶은가? (A/B/C/없음)
2. 어떤 모드에서 '아슬아슬하게 성공했다'는 재미를 가장 많이 느꼈나? (A/B/C/없음)
3. 어떤 조작 방식이 가장 자연스러웠나? (키보드 회피/마우스 회피/마우스 요격)
4. 각 모드의 재미를 1~5점으로 평가
5. 실제 롤·발로란트·오버워치 시작 전에 이 게임을 켤 의향이 있나? (1~5점 + 자유 의견)

## 관찰 기록

- 첫 성공까지 걸린 시간
- 게임 오버 후 자발적 즉시 재시작 여부
- 각 모드 생존시간의 **개인 내 변화량** (모드 간 절대값 우열 비교 금지)
- 게임 규칙을 묻는 횟수, 잘못 이해한 입력 빈도
- '사기 판정', '보이지 않았다', '조작이 답답하다' 같은 부정 피드백
- 최고 난이도 구간 전 프레임 드랍 여부

## Gate 결정 규칙

- 우선 탈락: 규칙 이해 실패, 반복적으로 납득 불가 피격, 조작과 결과의 불일치, 중대한 기술 오류.
- 1차 정성 판단: 자발적 재시작이 두드러지고, '아슬아슬한 성공'이 많은 모드를 우선.
- 동률일 경우: 더 단순한 조작, 짧은 설명, 안정적인 판정, 게임 전 워밍업 적합성을 우선.
- 셋 다 재미가 부족하면 반드시 메커니즘을 다시 설계한다. 디테일/효과음 추가만으로 해결하려 하지 않는다.
- 프로토타입 합격은 '게임의 재미'를 의미한다. **동체시력 측정 타당성이 검증됐다는 뜻은 아니다.** 그 검증은 별도 단계.
