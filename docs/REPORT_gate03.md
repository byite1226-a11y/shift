## 1. 구현 완료 기능

- A/B: 40초 CLEAR 제거. 충돌 전까지 무한 진행. 스케줄은 미리 만들지 않고 게임 시간 2.5초 앞까지 스트리밍 생성.
- LV.1~LV.10: 5초 간격, 45초 이후 LV.10 고정(파라미터 변화 없음). 레벨마다 간격·휴식·빠른 탄 상한·겹침 확률·빠른 탄 최소 간격·플레이리스트를 설정 파일로 관리.
- C: 코어 체력 3, 피해 쿨다운 500 ms, 독립 레벨 표(동시 표적 상한, 단계별 속도 비중). 체력 0이면 종료.
- Option B 투사체: 컨셉 패키지의 투명 PNG 소재를 그대로 회전·배치, 속도 비례 테이퍼 잔상(판정 제외). C는 15 px 판정 링 안에 같은 소재.
- 기록: Gate 03 런 레코드(모드·참가자·세션·seed·생존시간·도달 레벨·사망 원인·게임/난이도 버전·유효성·시각)를 별도 키에 저장. Gate 01/02 기록·IndexedDB 로그 보존, 혼합 없음.
- 랭킹 인터페이스 정의 + 로컬 구현(참가자별 최고 유효 기록 1개, 생존시간 내림차순, 동률 동일 순위). 서버가 없으므로 화면에는 순위·상위 %를 표시하지 않음.
- 시간 집계: 시뮬레이션 시간 / 플레이 중 실제 경과 / 일시정지(탭 비활성 포함) / 클램프로 버린 시간 / 최대 프레임. 기준 초과 시 `runValidity: suspect`(사유 포함). 봇 조작·이전 규칙 런도 suspect.
- 결과 화면(03_Game_Over_Clean 기준): SURVIVAL TIME → 도달 레벨(핍) → PERSONAL BEST / 최근 5판 평균 / 비교 기준 → 다시 도전 · 모드 선택. NEW BEST는 유효 런이 개인 최고를 넘을 때만.
- HUD(02_Gameplay_A 기준): 좌 SHIFT. + 모드, 중앙 타이머 + SURVIVAL TIME, 우 LEVEL nn + 10칸 핍 + BEST.

## 10. 알려진 문제 · 결정 필요 사항 (임의 확정 안 함)

1. **난이도 수치 전체**가 가설. 봇 B(제한 반응) 기준 g3는 Gate 02보다 분명히 어렵고(중앙 53.7초), 봇 A는 거의 죽지 않는다. 사람 기준은 플레이테스트로.
2. **봇 B 사망이 느린 대형탄 부채꼴·대형탄 교차에 집중**(fanLargeSlow 8/20). 대형탄 밀도가 과한지 확인 필요.
3. **C 체력 3**이 과한 완화인지는 사람 데이터로만 판단 가능. 클릭 없이 9.7초(LV.2)에 종료되므로 "무한 생존"은 아니다. 빠른 탄 LV.8 등장·쿨다운 500 ms도 가설.
4. **동시 투사체 상한 32**는 예고 확정(commit) 후 발사하는 탄 때문에 최대 2발 초과할 수 있다(관측 33). 상한은 목표가 아니므로 유지.
5. **유효성 기준**(클램프 손실 2 %, 평균 30 fps, 단일 프레임 1초)은 구현자가 정한 값. 온라인 랭킹에서는 서버 검증 필요.
6. **결과 화면**에서 랭킹 카드와 상위 %는 서버 데이터가 없어 제외. 시안의 "SEASON 01" 표기도 넣지 않았다.
7. **원형 판정 vs 체브론 실루엣**: 뒤 홈 부분은 색이 없는데도 판정 안(약 6 px). 비원형 판정은 별도 결정.
8. **잔상**은 한 차례 조정했으며 길이·두께·투명도는 디자인 판단에 따라 `render.ts`의 `streaks` 숫자로 조정 가능.
9. IndexedDB 라운드 로그는 라운드당 최대 ≈2.3 MB. 상한 60으로 통제하지만 플레이테스트 세션마다 다운로드 후 초기화를 권장.
10. `?sched=g1|g2`는 40초 CLEAR가 남아 있는 비교용 모드이며 기록은 suspect(legacy_rules).
